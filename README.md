# Netflix Data Analysis Project

## Project Overview
- This project focuses on analyzing Netflix data using Python, SQL, and Power BI.
- A dummy dataset was used to perform data cleaning, business analysis, and data visualization.
- The objective of this project is to extract meaningful insights from Netflix data and understand content distribution, trends, and business performance.

## Project Objectives
- Analyze Netflix content, including Movies and TV Shows.
- Identify trends in content distribution across different countries.
- Understand the distribution of Movies and TV Shows.
- Analyze content based on release years, ratings, and genres.
- Solve business-related questions using SQL.
- Create an interactive Power BI dashboard to visualize key insights.

## Tools & Technologies Used
- **Python:** Data cleaning and preprocessing
- **Pandas:** Data manipulation and analysis
- **SQL:** Business problem-solving and data analysis
- **Power BI:** Interactive dashboard and visualization
- **Jupyter Notebook:** Python development and analysis

## Project Workflow

### 1. Data Cleaning Using Python
- Imported the Netflix dummy dataset using Pandas.
- Checked for missing values and duplicate records.
- Handled missing and inconsistent data.
- Performed data type conversions where required.
- Cleaned and prepared the dataset for SQL analysis.
- Exported the cleaned dataset for further analysis.

### 2. Business Analysis Using SQL
- Imported the cleaned dataset into SQL.
- Used SQL queries to solve business-related problems.
- Applied SQL functions such as:
  - SELECT
  - WHERE
  - GROUP BY
  - ORDER BY
  - COUNT()
  - SUM()
  - CASE WHEN
  - Aggregate functions
- Analyzed Netflix content distribution and trends.
- Extracted meaningful insights from the dataset.

### 3. Dashboard Development Using Power BI
- Imported the cleaned dataset into Power BI.
- Created interactive visualizations and charts.
- Designed a dashboard to present key insights.
- Used filters and slicers for interactive analysis.
- Presented important business metrics in a clear and visually appealing format.

## Key Business Questions
- What is the distribution of Movies and TV Shows on Netflix?
- Which countries have the highest number of Netflix titles?
- How has Netflix content evolved over the years?
- Which genres are most popular on Netflix?
- What is the distribution of content ratings?
- Which years had the highest content releases?
- How does the distribution of Movies compare to TV Shows?

## Key Insights
- Analyzed the distribution of Movies and TV Shows.
- Identified content trends across different years.
- Explored country-wise content distribution.
- Examined genre and rating patterns.
- Developed insights to understand Netflix's content catalog.
